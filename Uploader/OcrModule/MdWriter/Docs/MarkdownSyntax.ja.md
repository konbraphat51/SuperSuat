# Markdownの文法

MdWriterパイプラインでモデルが書くMarkdownと、それを [MarkdownParser](../MarkdownParser.py) が
`OcrResult` に読み戻す方法です。プロンプト（[prompt.py](../Transcriber/prompt.py)）とパーサは
この1つの仕様に従っています。変えるときは両方を一緒に変えてください。

English version: [MarkdownSyntax.md](MarkdownSyntax.md)

## モデルが書くもの

1つの応答は、1ページ分のMarkdownです。

| 要素 | 書き方 | 備考 |
| --- | --- | --- |
| 段落 | 1行のテキスト | ページの都合で折り返された行は、文字体系に合わせて結合する。段落の間は空行 |
| 見出し | `## 見出し` | 文書のタイトルも含め、すべてレベル2（ページごとに独立して書くため、階層を揃えられない） |
| 図 | `![キャプション](figure:ID)` | 単独の段落にする。IDは図の赤枠に描かれた番号。キャプションは代替テキストにだけ書き、本文には重ねて書かない |
| 数式 | `$...$`、`$$...$$` | KaTeX互換のLaTeX。ディスプレイ数式は独立した行に書く |
| 表 | GFMの表 | 結合セルは、結合範囲のすべてのセルに同じ内容を書く |
| コード | フェンス付きコードブロック | ソースコードと疑似コード |
| 脚注 | 本文中に `[^n]`、定義は段落として `[^n]: 本文` | nは印刷されている記号。ページが違えば同じラベルを使ってよい |
| 傍注 | `:::sidenote` … `:::` | 余白の注記。隣にある段落の後ろに置く |
| コラム | `:::column` … `:::` | 本文から切り離された囲み、サイドバー、コラム |
| 目次 | `:::toc` … `:::`、1行に1項目 | [目次](#目次) を参照 |

書かないもの: ページ番号、柱（ランニングヘッド・フッター）、ページ画像に描いた赤枠とIDラベル。

図・脚注・傍注・コラムは、段落の中に入れません。段落の途中に
印刷されている場合は、段落を最後まで書いてから、その後ろにブロックを置きます。

各応答は、それだけで完結したMarkdownにします。囲みが次のページへ続いていても、
`:::` ブロックは応答の終わりまでに閉じます。ページが囲みの途中から始まる場合は、
応答の先頭でブロックを開き直します。ブロックは入れ子にしません。

### 目次

目次は `:::toc` ブロックに書きます。`:::toc` の行が目次の始まり、`:::` の行が終わりを示します。
中の1行が1項目です。

```markdown
## 目次

:::toc
- | はじめに | iv
- 第1章 | 総論 | 1
  - 1.1 | 背景 | 3
    - 1.1.1 | 歴史 | 4
- 第2章 | 方法 | 11
:::
```

| 部分 | 書き方 | 備考 |
| --- | --- | --- |
| 項目 | `- 番号 \| 題名 \| ページ` | `-` の代わりに `*`・`+` も可。点線（リーダー）は書かない |
| セクション番号 | 1つ目の欄 | 印刷どおり（`1.2`、`Chapter 3`、`第3章`）。番号がなければ空欄 |
| セクション名 | 真ん中の欄 | 空にしない。中の `\|` は `\\|` と書く |
| ページ番号 | 最後の欄 | 印刷どおり（`12`、`iv`）。印刷されていなければ空欄 |
| 階層 | 字下げ | 属する項目より半角空白2つ深くする（タブは4つ分） |

項目は見出しではありません。目次そのものの題（「目次」）は見出しとして、ブロックの前に書きます。

目次がページをまたぐ場合は、一方の応答の終わりで閉じ、次の応答の先頭で開き直します。継続マーカーは
付けません。次のページの項目は、目次全体での深さに合わせて字下げします。この変わり目はつなぎません
（段落としてつなぐと2つの項目が1行になってしまうため）。代わりにパーサが2つのブロックを1つにします。

### 継続マーカー

| マーカー | 位置 | 意味 |
| --- | --- | --- |
| `<!--continues-previous-->` | 応答の先頭 | 最初の段落は、前のページの最後の段落の続き |
| `<!--continued-by-next-->` | 応答の末尾 | 最後の段落は、次のページの最初の段落へ続く |

どのページも、自分のページ画像から判断してどちらも書けます。変わり目をつなぐかどうかは、その両側の
2ページの判断を合わせて決めます（[MdWriterOcr.ja.md](MdWriterOcr.ja.md#ページの変わり目) を参照）。
最初のページと最後のページに付いたマーカーと、`:::toc` ブロックの隣のマーカーは無視します。

続いている段落が囲みの中にある場合は、両方の応答が同じ名前の `:::` ブロックに入れて書きます。
[Stitcher](../Stitcher.py) が境界の閉じフェンスと開きフェンスを取り除くので、囲みは1つのブロックに戻ります。

### ページマーカー

ページマーカーはモデルには書かせません（書いた場合は取り除きます）。[Stitcher](../Stitcher.py) が
各ページのMarkdownの前に `<!--page:N-->`（Nは0始まり）を置きます。そのため、段落がページをまたいで
結合された所では、マーカーは改行なしで段落の途中に入ります。

## 検証

[MarkdownValidator](../MarkdownValidator.py) が、各応答を使う前に検証します。問題があれば
モデルに送り返し、応答全体を書き直させます。上限は `MAX_ATTEMPT_COUNT`（3回）です。

- そのページにある図がすべて、ちょうど1回ずつ置かれていること。ほかの図が置かれていないこと
- 図がそれぞれ単独の段落になっていること。図だけの行で、前後の行にテキストがないこと（`:::` のフェンスはよい）。
  そうでないと、パーサは図を段落の一部として読んでしまう
- 継続マーカーが先頭と末尾にだけ、それぞれ1回までであること
- `:::` のフェンスが対応していて、入れ子になっていないこと
- `:::toc` ブロックの中の行がすべて、題名のある `- 番号 | 題名 | ページ` の項目であること
- 40文字以上の段落が2回書かれていないこと（同じ部分を2回読んだときに起こる）

## 読み戻し

ページマーカーは、位置を記録したうえで、パースの前に取り除きます。HTMLコメントを残すと、
段落が途中で2つに分かれてしまうからです。独立した行にあるマーカーは行ごと取り除くので、
その場合も段落は分かれません。

| Markdown（最上位） | `OcrResult` |
| --- | --- |
| 段落・リスト・引用・HTML | `paragraph`（`[^n]:` で始まる段落は `note`。コメントだけのHTMLブロックは捨てる） |
| 見出し | ルート直下に新しい `OcrResultSection` を開き、`heading` ブロックと、次の見出しまでの内容を入れる |
| フェンス付き・インデントのコード | `code`（フェンスを除いたコード） |
| `$$` ブロック | `math`（`$$` を除く） |
| 表 | `table` |
| `:::sidenote`、`:::column` | `note`（中のテキスト）。中にある図だけの段落は、noteの直後の `OcrResultBlockFigure` にする |
| `figure:ID` の画像1つだけの段落 | `OcrResultBlockFigure`。枠とページは検出結果から、キャプションは代替テキストから取る |
| `:::toc` | `OcrResultBlockTableOfContents`。項目を `TableOfContentsEntry`（`section_number`・`title`・`page_number`・`children`）の木にする。空欄は `None` |

間にページマーカーしかない `:::toc` ブロックは1つの目次とし、項目を1つの並びとして読みます。
直前の項目より深く字下げされた項目はその下に入れ、どの項目の下でもない項目は最上位にします。
項目でない行は読み飛ばします。

ブロックのテキストは、書かれたMarkdownのソースそのものです。リンク参照定義は無効にしています。
有効のままだと `[^1]: note` がリンク参照定義として読まれ、消えてしまうからです。

ブロックの `existing_pages` は、ブロックが始まるページと、ブロックの最後のテキストより前に
マーカーがあるすべてのページです。セクションの値は、その中身の和集合として計算し直します。

検出されていないIDの図や、2回目に置かれた図は、警告を出して捨てます。検出されたのに
一度も置かれなかった図は、警告を出したうえで、その図があるページの最後のブロックの後ろに置きます。
