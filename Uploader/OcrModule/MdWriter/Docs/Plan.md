1. レイアウト・バウンディングボックスモデルにて、図の領域を検出

- モデルにはDocLayoutYolo, Yomitoku, PpStructureを選択可能にする
- 文章画像上に、検出された図領域のバウンディングボックスと、そのユニークIDを描画
- 検出するのは図（figure / image / chart）のみ。表と数式はLLMがMarkdownで書き下す
- Blockedの `Blocker` は変更せず、MdWriter側に図専用の `FigureDetector` を別に実装する

2. LLMに、文書画像を渡し、マークダウンへ変換するよう指示

- バッチ数を`BATCH_SIZE`として、
  1. 最初は[BATCH_SIZE*x, BATCH_SIZE*(x+1)]（xは任意の偶数）の範囲で、文書画像をLLMに渡して書き下させる（並列）
  2. LLMから返却されたマークダウンの穴を埋めるように[BATCH_SIZE*x, BATCH_SIZE*(x+1)]（xは任意の奇数）の範囲で、文書画像をLLMに渡す（並列）
  - 2に関して、LLMに与えるマークダウンデータは対象バッチ（2で書き下すもの）の前後バッチ（1から得られたもの）のみを与える。
- 範囲は閉区間。隣り合うバッチは境界の1ページを共有する
  - 偶数バッチは自分の全ページを書き下す
  - 奇数バッチは、偶数バッチが書き下していない内側のページだけを書き下す。境界ページの画像は、前後のつながりを読むための文脈として渡す
  - 奇数バッチの出力は「前バッチ + 自分の出力 + 後バッチ」が1つの文書として続くように書かせる。段落が境界をまたぐときは、継続マーカーで示させる
  - `BATCH_SIZE` は2以上
- 脚注・傍注・コラムなどに対して特殊文法を定義し、LLMに使用させる（[MarkdownSyntax.ja.md](MarkdownSyntax.ja.md)）
  - 脚注はGFM形式（`[^n]` / `[^n]: …`）、傍注とコラムは `:::sidenote` / `:::column` ブロック
  - 各ページの書き始めに `<!--page:N-->` を置かせ、ブロックがどのページにあるかを記録する
- 見出しはすべてレベル2として扱う（バッチごとに独立して書くため、階層は揃えられない）

3. 結合したMarkdownを解析し、`OcrResult` に変換する
